# Financial Scenario Analysis

DAA / Parallel Programming Mini Project

## Problem Statement

Develop a computational system for evaluating a large number of financial scenarios according to specified criteria. Investigate how execution time changes with the number of scenarios.

## Project Objective

The project will:
1. Define a financial scenario and its evaluation criteria.
2. Implement a sequential solution.
3. Implement a parallel solution using an appropriate parallel programming model.
4. Verify that the sequential and parallel solutions produce correct results.
5. Compare their performance for different input sizes and execution configurations.
